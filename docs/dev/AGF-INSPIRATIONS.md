# AGF 对 AG2C 的帮助：宪法与判例法

> 背景：AGF（七维信任坐标系）是项目家族的第三个成员——effect / contract /
> meaning / quality / decider / grain / failure 七维封闭枚举，统一三兄弟的
> "默认可信范围"。本文记录它对 AG2C 已经兑现和即将兑现的帮助。
>
> 状态：第一轮对照结论（2026-09-11 讨论确认），四阶段路线已经用户决策。

## 一、定位：宪法与判例法

AGF 与 AG2C 的关系是**宪法与判例法**：

- AG2C 是判例法——每个任务、每次事故、每个机制（巴林条款、棘轮、危房、
  普查……）都是一个判例，先在实战里跑出问题和对策。
- AGF 是宪法——**刻意滞后**，不领先于实践。每个 AG2C minor 版本后跑一次
  反投影测试作为修宪仪式：把 AG2C 的机制投影到七维坐标上，照出坐标系
  表达不了的东西，才修宪。

宪法不指导日常断案，只定期吸收判例。这样 AGF 不会沦为空中楼阁，
AG2C 也不会因为宪法太细而动弹不得。

## 二、已兑现：反投影测试第一轮抓到 5 个洞

把三兄弟的现有机制投影到七维上，第一轮就发现坐标系的 5 个洞：

- **A 组合风险**：单条机制各自合法，组合起来越界（巴林条款治的就是这个）
  ——坐标系必须能表达组合，不能只给单动作打分。
- **B decider 缺档且单值**：没有"AI 裁决"档，且一个动作只有一个 decider
  值——修法：+advisor 字段。此洞后来在 AG2K 信任阶梯讨论中复现，
  修法进化为 decider 按层级分档（L0/L1=machine，L2=machine+证据，
  L3=human/offline）——说明洞是真的，不是测试的假阳性。
- **C 元层动作无家**：治理治理的动作在坐标系里没位置——处置：划出界外，
  元层保持单一固定姿态，不参与坐标游戏。
- **D 认知副作用**：effect 维没有认知类（读了 prompt injection 会改变
  AI 的判断）——修法：effect+cognitive。
- **E 禁令无表达**：preset 只能说能做什么，不能说禁止什么——修法：
  preset 加 forbidden 列表。

另有维度间约束假说：quality=human → decider≥confirm 这类规则**可机查**
——可以直接变成 AG2C 的 checker，让坐标申报不只是填表。

## 三、责任路由 → 坐标系：AG2C 的教训成了 AGF 的默认姿态

AG2C 最初是"不出错不管、出错追责"——对 AI 完全失效（差异 3.1：
无威慑感受器，惩罚与羞耻对 AI 是空气），被逼出预防机制。

这条教训写进了 AGF 的默认姿态：**默认最乐观档必须配三件套**——

1. 坐标申报（动作进场先报七维坐标）；
2. 对账（声明 vs 实际，机器可查）；
3. 自动降档棘轮（对账不符就降档，只下不上）。

乐观可以，但乐观必须自带刹车。这正是主线图景（坐标进场→对账→棘轮→
分拣→终点是用户）在坐标系上的投影。
